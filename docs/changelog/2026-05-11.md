title: 5月11日更新
date: 2026-05-11

### Added
- 新增聊天消息文字渐变颜色配置，支持系统、被提及、队伍、好友、普通、客户端 `echo` 分别设置。
- 重做消息颜色设置 UI 为“文字 + 重置”布局，并新增可增减颜色区块。
- 接入实际聊天渲染和预览渲染，按文字内容生成渐变。
- 保留原单色配置作为默认颜色与单色回退。
### Fixed
- 复用现有多色文本分段能力，避免逐帧重复拆分渲染。
- 兼容 `UTF-8` 文本渐变分段，避免中文按字节切分导致错位。
- 保留客户端内联颜色标记优先级。
- 设置页改色后立即重建聊天文本容器，保证预览和实际显示同步。
### Removed
- 移除旧的“单个颜色块 + 重置”消息设置布局。
- 删除每类消息只能设置单色的 UI 限制。
