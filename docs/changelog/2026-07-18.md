### Added
- 为交换、队伍切换和禁言状态增加液态卫星提示、倒计时环及入退场动画
- 增加交换方向、完成状态、旁观人数和多连接状态展示
- 新增媒体岛圆形专辑封面，并将遮罩处理迁移至后台任务
- 引入 Lucide 卫星图标，扩展图集生成器的 SVG 路径和圆弧支持
- 接入 DDNet 官方地图分类表，增加更新脚本并动态调整补全弹窗宽度
- 优化媒体岛底部内容宽度，避免歌词或工具信息不必要地撑宽布局
- 补充媒体岛、Axiom 登录、交换、地图分类和画面比例测试
- 更新客户端版本号到 `2.75.14`
### Fixed
- 修复交换消息未区分传入、传出及主副连接的问题
- 修复 Axiom 自动登录过早重试、延迟回复误判和连接发送错误
- 修复媒体岛显示无效 Team 0、状态重叠和顶部特效避让异常
- 分离游戏世界与 UI 的宽高比映射，避免自定义比例影响 UI、地图、触控和多视角
- 调整计分板队伍标题对齐方式
