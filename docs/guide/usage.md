## 初次使用 
首先进入`QQ`群之后,在群文件的日期分类中找到最新日期且内部含有`QmClient-android.apk`  `QmClient-ubuntu.tar` `QmClient-macOS.dmg` `QmClient-windows.zip`的文件夹  
其中`QmClient-windows.zip`就是大部分人所需要下载的;实际上你应该根据你自己的需求来  
下载了`QmClient-windows.zip`之后选择解压缩(包括但不限于Windows自带的解压,7zip,bandizip,Winrar,360解压缩,2345快压,WPS解压等)之后正常游玩即可

::: tip 小提示
从上述列举的名称依次为  
安卓用户所需  
Linux用户所需  
苹果用户所需  
Windows用户所需
:::

下载下来之后解压,然后找到群文件找到最新的`DDNet.exe`,替换即可  
如果你超级幸运在进群的当天就发布了`QmClient-windows.zip`  (或者其他你所需要的)  
请您:<span style="font:italic 30px cursive;background:linear-gradient(to right,#ff6a00,#ff2d55,#007aff);-webkit-background-clip:text;-webkit-text-fill-color:transparent;display:inline-block;">Just Do It</span>

## 后续更新 
1. 有FIX文件夹的情况下:
之后的每一次更新都会发送完整压缩包
但是严重BUG的时候会单独发送一个FIX,即(DDNet.exe)
这时候你就需要把你QQ下载的这个DDNet.exe自行拖入你之前下载的压缩包里面去
正常情况下会提示"你已有XXXXX,是否需要替换"选择替换即可
2. 没有FIX文件夹的情况下:
	1. 在你在客户端文件夹内新增了包括但不限于:音效,强弱钩,方向,鼠标等内容时:
		你应该把新压缩包解压之后的内容拖入你原先的,选择替换即可
	2. 你并没有新增任何内容或者你明白这些东西更应该存`%appdata%/DDnet`下时:
		删除旧的用新的或者直接用新的或者替换都一样

::: note 注意!
为什么不把原来的删掉而是去替换是因为有些人的cfg是放在客户端目录下的
:::
